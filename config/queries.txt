# MAPPA 2.0 discovery search terms (Task 01, M1). DRAFT for Alex's review.
#
# Each term is searched once on Google Play with country="au", lang="en".
# Format: one term per line. "## <name>" starts a category (used only to group counts
# in SAMPLING.md). Other lines starting with "#" are comments. Blank lines are ignored.
#
# How the terms were chosen:
# - Generic phrases people type, not brand names, so no company is favoured. Apps that
#   must be in the sample regardless of search go in seed_apps.csv instead.
# - Australian wording where it differs (chemist, GP, bulk billing, eScript, Medicare,
#   pathology, counselling, immunisation, centre, colour, apnoea).
# - Some terms overlap on purpose: a search returns only one page of results, so
#   overlapping terms reach further down the same niche. Duplicate apps are merged by
#   package name.
# - The last category is outside the task's topic list: keep or delete.
